## 真实 macOS WebView 验收

执行：

```sh
PTD_STAGE_A_GUI=1 VITE_STAGE_A_GUI=1 \
PTD_E2E_DATA_DIR="$(mktemp -d)" pnpm tauri dev
```

必须使用新建、绝对路径的隔离目录。Rust 验收模块只在 debug 构建且两个 Rust 环境条件同时满足时启用；前端只在 Vite 开发模式且显式启用时运行。辅助窗口仅在这个场景中获得 storage 权限，发布版仍只允许 main 业务窗口。

本次目录：工作区 `.stage-a-gui.xYPXut`（归档证据后删除）。实际创建两个原生 WebView，经生产 storage IPC 提交旧快照，随后释放、重建主应用并正常关闭。结构化结果见 [AP-A-gui.json](./AP-A-gui.json)，原生主窗口销毁记录见 [AP-A-gui-closed.txt](./AP-A-gui-closed.txt)。两窗口与应用进程均退出。初次演练发现缺少窗口销毁权限，已补 `core:window:allow-destroy`，最终新目录演练无释放错误。

验收辅助窗口不挂载业务 worker；两窗口的写入竞争使用真实 IPC 和 JSON 存储。业务 worker 的等待/失败/重建协议由可控 Promise 测试验证，持久租约归还由 AP-09 验收。

## 写入与敏感字段边界

- 根配置权威写入：`extStorage.mergeItem`、`mergeBatch`；持有读取基线的兼容 `setItem` 转为相同条件提交。Rust 禁止 `set_ext_storage` 覆写 config/metadata。
- Pinia 设置保存、后台时间/账号状态、站点运行设置与备份恢复均经过以上入口。已移除 store 插件及权限，架构门禁拒绝重新导入插件或从业务文件直接调用写入 IPC。
- 密码、Token、备份密钥及站点运行凭据只保留在实体配置/专用配置字段；列表摘要不包含这些字段。Cookie 仍为独立本地明文文件，默认备份不包含它。
- 历史/任务只保留执行资源 ID、公开种子信息和普通下载选项；签名 HTTP 下载链接不落盘。恢复后的种子需要即时重建地址，不能重建时明确失败。
- 用户统计缓存只保留已知统计与显示字段；社交缓存只保留已知作品字段，并裁剪图片 URL 查询。favicon 生产缓存来自图像转换，不保存站点请求对象。runtime 不再写 sessionStorage。
- 设置编辑按 ID 读取完整实体；列表只给摘要。高级下载选项在执行时读取完整下载器配置，不复制到上次下载选项。
